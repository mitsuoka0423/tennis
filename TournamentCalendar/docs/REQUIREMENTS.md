# 草トーナメント横断カレンダー 要求定義（v1.0）

## 1. 背景・課題

- 草トーナメント（以下、草トー）の募集情報は、主催ごとの Web ページに分散している
- 「いつ・どこで・どの草トーがあるか」を知るには、複数サイトを個別に巡回する必要がある
- その結果、以下が起きる
  - 申込締切を見落とす
  - 同日開催の大会を比較できない
  - 自分のレベル・種目に合う大会を探しにくい

## 2. 目的

参加候補の草トーの開催情報を **1箇所で一覧できる** ようにし、
大会探しと申込判断にかかる手間を減らす。

## 3. 利用者

| 利用者 | 説明 |
|---|---|
| 利用者 | 本人のみ（草トーによく参加するプレーヤー） |

共有・複数ユーザーは想定しない。ログイン機能は持たない（公開範囲の制限方法は設計で決める）。

### 主な参加条件（既定の絞り込み）

地域は条件にしない。収集対象サイトが関東の大会に限られるため。

| 項目 | 条件 |
|---|---|
| 種目 | 男子シングルス |
| 曜日 | 休日（土日・祝日） |
| レベル | 中級・中上級 |

## 4. 利用シーン

1. 週末前に「今後1か月で出られる大会」をざっと見る
2. 特定の日付に空きがあり、その日に開催される大会を探す
3. 気になる大会の申込締切が近いことに気づき、元ページから申し込む

## 5. 機能要求

| ID | 要求 | 優先度 |
|---|---|---|
| FR-1 | 収集対象サイト（7章）から大会情報を自動収集できること | Must |
| FR-2 | 収集した大会を開催日順に一覧表示できること | Must |
| FR-3 | 各大会について、少なくとも以下を表示できること: 大会名・開催日・会場・種目（シングルス/ダブルス/ミックス等）・レベル・申込締切・募集状況・元ページへのリンク | Must |
| FR-4 | 元ページへ遷移して申し込めること（申込自体は本システムで代行しない） | Must |
| FR-5 | 収集対象サイトを追加・削除できること | Must |
| FR-6 | 日付・曜日（休日）・種目・レベルで絞り込めること。既定値は3章の参加条件とする | Must |
| FR-7 | （欠番）カレンダー形式（月表示）は不要と決定。8章へ移した | — |
| FR-8 | 参加条件に合う新着大会・申込開始・締切間近・空き発生を Discord に通知できること。通知は毎日20時に1回まとめて送る | Must |
| FR-9 | Google カレンダー等へ取り込める形式（iCal）で出力できること | Could |
| FR-10 | 気になる大会をブックマーク・参加予定として記録できること | Could |

- FR-6 の「レベル」はサイトごとに表記が異なる（例: クローバーカップ「中級以上」、レオーネカップ「中上級」「オープン（グレードC）」）。
  サイト横断の対応表を設計で定める

## 6. 非機能要求

| ID | 要求 |
|---|---|
| NFR-1 | 情報の鮮度: 1日1回以上、元サイトの情報を反映すること |
| NFR-2 | 正確性: 元ページの情報を正とし、常に元ページへのリンクを示すこと |
| NFR-3 | 元サイトへの配慮: 各サイトの利用規約・robots.txt に従い、アクセス頻度を抑えること |
| NFR-4 | 収集の失敗（サイト構成変更など）に気づけること |
| NFR-5 | Web ページとして提供し、スマートフォンのブラウザで見やすいこと |
| NFR-6 | 運用コスト: 個人利用で無料〜低額に収まること |

## 7. 収集対象サイト

2026-10-12 時点の予備調査結果。

| ID | サイト | URL | robots.txt | 取得方法の見込み |
|---|---|---|---|---|
| `clover` | クローバーカップ（NPOテニスネットワーク） | https://tennis-net.jp/clover | 大会ページは許可 | 静的 HTML に大会名・開催日・会場・グレード・申込状況がある。取得容易 |
| `leone` | レオーネカップ 男子シングルス | https://leone-tokyo2022.com/mens-singles/ | 大会ページは許可 | 静的 HTML の表に日時・大会名・レベル・会場がある。空き状況は詳細ページ側の可能性あり |
| `inspirits` | インスピリッツ 試合一覧 | https://reserve.inspirits-tennis-club.com/reservations/calendar | robots.txt なし。ページに `noindex,nofollow` | 一覧は JavaScript で後から読み込まれ、HTML に大会情報が無い。自動取得はユーザー判断で可。一覧は `POST /ajax/reservations/calendar` から読み込まれている |

## 8. スコープ外（初期）

- カレンダー形式（月表示）。一覧と絞り込みで足りるため（旧 FR-7）

- 大会への申込・支払いの代行
- 大会結果・ランキングの管理
- 主催者による大会情報の直接投稿

## 9. 制約・リスク

- 収集対象サイトの HTML 構造はサイトごとに異なり、変更もありうる。サイトごとの取り込み処理が必要になる
- 利用規約でスクレイピングを禁止しているサイトは対象にできない
- 大会情報の項目名（レベル表記など）はサイトごとに揺れがあり、正規化が必要

## 10. 決定事項

| 項目 | 決定 |
|---|---|
| 利用者 | 本人のみ |
| 提供形態 | Web ページ |
| 通知手段 | Discord（毎日20時に1回まとめて送る） |
| inspirits の自動取得 | ユーザー判断で可とする |
| 画面 | 一覧と絞り込みのみ |
| 閲覧範囲 | 家の LAN 内のみ。外出先は Discord 通知のリンクから元ページへ |
| 実行基盤 | 自宅サーバー（home-server リポジトリで管理） |
| 地域の判定 | 行わない（収集対象サイトが関東に限られるため） |
| 置き場所 | 本リポジトリ（モノレポ化）の `TournamentCalendar/` |
